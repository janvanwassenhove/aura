# Full audit — security, a11y, UI/UX, performance (Aug 2026)

Four parallel audits over the repo, each finding verified against the actual
code. This is the consolidated, de-duplicated backlog. Items marked **[fixed]**
landed in the units noted; the rest are ranked for follow-up.

## Security (highest stakes)

| # | Sev | Issue | Status |
|---|---|---|---|
| S1 | critical | Brain bound `0.0.0.0:8020` with **no auth** on any endpoint → any LAN neighbour reads knowledge/OAuth tokens and has an RCE chain | **[fixed U215]** → loopback default |
| S2 | critical | `.env` value injection (unescaped newline) via `/setup/prefs`, `/robot/address` → persisted env vars → RCE next launch | **[fixed U215]** newline/key sanitised |
| S4 | high | No Host/Origin validation → DNS-rebinding defeats CORS (drive-by full control) | **[fixed U215]** TrustedHost + Origin guard |
| S6 | high | `/recognition/merge` erased a person with no confirm; whole `/recognition` router ungated | **[fixed U215]** merge needs `confirm=<id>` |
| S3 | critical | `GET /identity/token/{user}/{provider}` returns the **raw OAuth access token**, no auth | **deferred** — now loopback-only (S1); legacy HTTP seam, the brain uses in-process tokens. Recommend deleting the route. |
| S5 | high | robot-runtime binds `0.0.0.0:8001` on the Pi (camera+mic+motion) unauthenticated | **[fixed U220]** opt-in `ROBOT_SHARED_SECRET` guard on the Pi (hmac.compare_digest; `/health`+docs exempt); every brain→robot client sends it. Still bound to the LAN by design. |
| S7 | med-high | SSRF via `/robot/address` (GET + body-read + persisted) | partially mitigated by S1/S4; add a link-local/metadata block (LAN must stay allowed — the robot lives there) |
| S9 | med | Static default KDF salt `aura-knowledge00` + scrypt n=2^14 + 8-char min passphrase (env-configured path only; `/setup/secure` already randomises) | **done (U225)** — salt + work factor moved into `key-params.json` beside the ciphertext; random 16-byte salt per install, scrypt n=2^17, min passphrase 12. Existing installs rotate in place on boot (rewrap DEKs + re-encrypt embeddings); the bundles are not re-encrypted. |
| S10 | med | Knowledge passphrase stored plaintext in `.env` beside the ciphertext | **done (U225)** — passphrase moved to the OS keyring (Windows Credential Manager/DPAPI). `KNOWLEDGE_PASSPHRASE` still wins when set, for docker/CI/headless. |
| S11 | med | Auto-update installer run with no signature/checksum; asset name interpolated into a `.cmd`; staged in `%TEMP%` | **[fixed U224]** releases publish `SHA256SUMS.txt`; the asset is verified before staging, the name is refused unless a plain filename, staging moved to userData. |
| S12 | med | `/robot/discover` + `/setup/discover` are GET LAN port-scans (CSRF-triggerable) | mitigated by S4 Origin guard; make POST-only |
| S14 | low-med | `/knowledge/unlock` passphrase oracle, no rate-limit, non-constant-time compare | **[fixed U221]** constant-time compare + exponential backoff after 5 failures (429 with retry_after_s). |
| S15 | low | `shell.openExternal` accepts any renderer URL; DevTools in prod menu | **[fixed U221]** `EXTERNAL_ALLOW` list for `setWindowOpenHandler`; DevTools only when not packaged. |

**Verified OK (do not re-audit):** Electron core (`contextIsolation:true`, `nodeIntegration:false`, tiny preload); static console binds loopback with a path-prefix check; `yaml.safe_load` everywhere, no `eval`/`shell=True`; skill/scenario name regex blocks traversal; subprocess uses argv lists + an allow-list; AES-256-GCM with per-write random nonce and AAD binding; no secrets in responses/logs; `.env` gitignored.

## Accessibility (WCAG)

**[fixed U216]** `--text-faint` contrast in both themes (was 2.4–3.8:1). Pending:
modals lack Escape/focus-trap/restore (2.1.2/2.4.3) — 5 overlays; capability
toggles unnamed, need `role="switch"` (4.1.2); toggle grid / pv-toggle / gf-chip
need `aria-pressed`; conversation + approval + robot-offline need live regions
(4.1.3); canvas graph has no text alternative or keyboard path (1.1.1/2.1.1);
aim pad + splitters are pointer-only (2.1.1); placeholder-only inputs (3.3.2);
no `prefers-reduced-motion`; `<html lang>` vs Dutch strings (3.1.2); accent
white-on-green/amber fails AA on buttons (1.4.3 — needs a design call, see below).
**Done well:** global `:focus-visible`, fully-labelled TitleBar, correct
`role=status` on strips, proper `<label for>` in the wizard.

## UI/UX

**[fixed U216]** `--radius-md`/`--accent-contrast` undefined → ~60 square-cornered

## Performance

Pending, ranked: **P1** perception pulls a 2 MB **PNG** every 2 s (measured 84 ms
encode) for a format the embedder doesn't need → point it at `/camera/frame.jpg`
(2 MB→19 KB); **P2** `downscale_jpeg` uncached, two console pollers ≈ one Pi core
→ cache by source-frame identity; **P3** BrainGraph `requestAnimationFrame`
repaints 60 fps forever after the sim settles → stop rescheduling past `ticks`;
**P4** `RecognitionGallery` keeps 6×2 MB PNGs/person in RAM → store thumbnails;
**P5** `selectGraph` N sequential fetches → one `GET /knowledge/export`; **P6**
insightface loads on the event loop at boot → lazy background init. P1/P2/P4
need a Pi redeploy. **Checked and NOT worth fixing:** encrypted-store decrypt
cost (0.09 ms/bundle), demo seeding, realtime resampling, voice loop, bundle
splitting over localhost.
